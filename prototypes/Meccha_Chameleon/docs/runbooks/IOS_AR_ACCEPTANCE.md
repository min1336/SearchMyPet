## iPhone 14

- [ ] 설치와 첫 실행이 성공하고 카메라 권한 설명이 정상적으로 보인다.
- [ ] 권한 허용 후 카메라 배경과 AR 세션이 시작된다.
- [ ] 밝고 특징이 충분한 공간에서 10초 안에 수평 평면을 찾는다.
- [ ] 벽을 비추면 수직 평면을 찾는다.
- [ ] 수평·수직 평면에서 미리보기 위치와 방향이 자연스럽다.
- [ ] 미리보기 이동 중 캐릭터가 중복 생성되지 않는다.
- [ ] 확정 후 캐릭터가 Anchor에 고정되고 기기를 움직여도 과도하게 흔들리지 않는다.
- [ ] 확정 후 평면 시각화가 사라지고 추가 배치 입력이 차단된다.
- [ ] Reset 후 Anchor와 캐릭터가 사라지고 다시 배치할 수 있다.
- [ ] 배치·확정·Reset 10회 반복에서 crash, exception, 유령 오브젝트가 없다.
- [ ] 상태 패널과 버튼 클릭이 배치 입력으로 전달되지 않는다.
- [ ] 세로·가로 회전에서 Safe Area와 버튼이 잘리지 않는다.
- [ ] 권한 거부 시 원인을 설명하고 배치를 허용하지 않는다.
- [ ] 빠른 움직임·어두운 환경·특징 부족에서 적절한 추적 안내를 표시한다.
- [ ] 홈 이동 후 복귀와 화면 잠금 해제 뒤 앱이 복구된다.

## 합격 기준

- 두 기기에서 모든 항목을 통과합니다.
- 테스트 중 처리되지 않은 예외, crash, Anchor 잔존이 없습니다.
- 반복 배치 결과와 Console log, 최소 한 개의 화면 녹화를 각 기기별로 남깁니다.
- 실패 항목은 재현 단계, 환경, 로그, 영상과 함께 이슈로 분리합니다.

Android/ARCore, Cloud Anchors, GPS, 서버 동기화, 기기 간 공유, 50m 콘텐츠 경계는 이 체크리스트의 대상이 아닙니다.
