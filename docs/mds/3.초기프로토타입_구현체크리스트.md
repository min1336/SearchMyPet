# CAMO HUNT AR 초기 프로토타입 구현 체크리스트

> **에이전트 작업자 필수 지침:** 이 계획을 구현할 때 `superpowers:subagent-driven-development`(권장) 또는 `superpowers:executing-plans`를 사용하고, 아래 체크박스를 완료 즉시 갱신한다.

**목표:** 현재 로컬 AR 배치 프로젝트를 제한 팔레트 위장과 한 기기 숨기기·찾기가 가능한 iOS 초기 프로토타입으로 확장한다.

**아키텍처:** 기존 `ARPlacementController`가 AR Raycast와 로컬 Anchor를 계속 소유한다. 새 `Camouflage` 계층은 팔레트 데이터와 런타임 Material을, 새 `Game` 계층은 `Scanning → Painting → Placing → Finding → Result/TimedOut` 전이를 소유하며 이벤트로 배치 계층과 연결한다.

**기술 스택:** Unity 6000.5.4f1, C# 9, AR Foundation/ARKit 6.5.0, Input System 1.19.0, uGUI, NUnit/Unity Test Framework, XR Simulation, iOS 15 이상.

**선행 문서:** [전반적인 게임 기획](0.전반적인게임기획.md), [초기 프로토타입 범위](1.초기프로토타입_범위.md), [현재 프로젝트 개선 및 개발 계획](2.현재프로젝트_개선및개발계획.md)

## 전역 제약

- 첫 프로토타입은 한 기기·한 앱 세션·한 캐릭터만 지원한다.
- 색칠은 고정 팔레트 8색과 Prefab에 지정된 2~4개 논리 영역으로 제한한다.
- 사진, 이미지, 텍스처 업로드와 자유 UV 브러시는 구현하지 않는다.
- GPS, 50m, Cloud Anchor, 계정, 서버, 보상, 컬렉션은 구현하지 않는다.
- `sharedMaterial`과 원본 Material asset을 런타임에 수정하지 않는다.
- XR Simulation은 로직 회귀용이며 완료 판정은 실제 iPhone/iPad 카메라와 ARKit Anchor 시험으로 한다.
- 각 Task는 실패 테스트 → 최소 구현 → 전체 회귀 → 커밋 순서로 끝낸다.
- `CamoHuntAR/Assets/CamoHuntAR/Tests/Scenes/ARPlacementScene.unity`는 테스트 fixture이므로 프로덕션 씬 대신 수정하지 않는다.

## 공통 실행 변수와 판정 방법

모든 PowerShell 명령은 저장소 루트 `C:\Projects\Meccha_Chameleon`에서 실행한다.

```powershell
$UnityExe = "C:\Program Files\Unity\Hub\Editor\6000.5.4f1\Editor\Unity.exe"
$RepoRoot = (Get-Location).Path
$UnityProject = Join-Path $RepoRoot "CamoHuntAR"
$Artifacts = Join-Path $RepoRoot "artifacts"
```

특정 테스트 실행 함수:

```powershell
function Invoke-UnityTests {
    param(
        [ValidateSet("EditMode", "PlayMode")]
        [string] $Platform,
        [string] $ClassName,
        [string] $ResultStem
    )

    & $UnityExe -batchmode `
      -projectPath $UnityProject `
      -runTests -testPlatform $Platform `
      -testFilter $ClassName `
      -testResults (Join-Path $Artifacts "$ResultStem.xml") `
      -logFile (Join-Path $Artifacts "$ResultStem.log")

    if ($LASTEXITCODE -ne 0) {
        throw "$ClassName failed with exit code $LASTEXITCODE."
    }
}

Invoke-UnityTests "EditMode" `
  "CamoHuntAR.Tests.PaletteDefinitionTests" `
  "task1-palette"
```

각 Task에서 명시한 실제 test filter를 `ClassName`으로 넘긴다. 성공 조건은 프로세스 종료 코드 `0`, XML의 `failed="0"`, 로그에 `error CS`, `Unhandled Exception`, `NullReferenceException`이 없는 것이다.

전체 회귀:

```powershell
& $UnityExe -batchmode `
  -projectPath $UnityProject `
  -runTests -testPlatform EditMode `
  -testResults (Join-Path $Artifacts "editmode-prototype.xml") `
  -logFile (Join-Path $Artifacts "editmode-prototype.log")

& $UnityExe -batchmode `
  -projectPath $UnityProject `
  -runTests -testPlatform PlayMode `
  -testResults (Join-Path $Artifacts "playmode-prototype.xml") `
  -logFile (Join-Path $Artifacts "playmode-prototype.log")
```
