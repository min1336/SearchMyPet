# Task 01 — AR 수직 벽면 탐지 스파이크

## 목적

빈 AR 씬에서 수직 벽이 실제 기기에 탐지되는지 먼저 증명한다. 이 Task는 배치 게임을 만들기 위한 작업이 아니라 가장 큰 기술 위험을 제거하는 스파이크다.

## 선행 조건

- [x] Task 00의 플랫폼·패키지·테스트 기기 결정

## 작업

- [ ] `<UNITY_PROJECT_ROOT>/Assets/Scenes/WallPlacementValidation.unity`를 만든다.
- [ ] AR Session, XR Origin(AR), AR Camera를 배치한다.
- [ ] `ARPlaneManager`, `ARRaycastManager`, `ARAnchorManager`를 구성한다.
- [ ] Plane detection을 `Vertical` 중심으로 설정한다. 수평 평면은 배치 후보로 쓰지 않는다.
- [ ] 개발용 Plane 시각화와 탐지 상태 문구를 추가한다.
- [ ] 권한 거부, AR 미지원, 세션 실패에 빈 화면 대신 재시도 가능한 안내를 표시한다.
- [ ] 실제 벽을 20~30초 스캔해 수직 Plane 탐지 수와 상태를 기록한다.

## 수용 기준

- [ ] 선택한 실기기에서 카메라 권한을 얻고 AR 세션이 시작된다.
- [ ] 실제 수직 벽에서 하나 이상의 수직 Plane이 탐지되고 개발용 시각화 또는 로그로 확인된다.
- [ ] 권한 거부·미지원 상황이 예외나 무응답이 아닌 안내 UI로 처리된다.

## 제외

최종 UI, 캐릭터 모델, 탭 배치, 영속성.
