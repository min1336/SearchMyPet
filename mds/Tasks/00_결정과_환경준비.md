# Task 00 — 결정과 환경 준비

## 목적

구현 전에 대상 플랫폼, 실기기, Unity·XR 패키지 조합, 빌드 책임을 고정한다. 지원 기기 없이 에디터에서만 진행하는 상태를 완료로 간주하지 않는다.

## 플랫폼 전략

기본 권장은 **iOS ARKit 단일 기기군으로 첫 기술 검증을 통과**하는 것이다. 벽면 pose·UX·anchor 문제를 플랫폼 차이와 분리해 빠르게 확인하기 위해서다. 이 판정 명칭은 `Wall Placement Technical Go (iOS)`이며, 제품 전체 또는 크로스플랫폼 통과를 뜻하지 않는다.

Android가 출시 필수 시장이거나 현재 확보한 대표 실기기가 Android뿐이면, 같은 원칙을 ARCore에 적용해 1차 플랫폼을 Android로 변경할 수 있다. 어느 경우든 반대 플랫폼은 1차 통과 직후 별도 호환성 스파이크로 검증하며, 두 플랫폼의 결과 전에는 크로스플랫폼 MVP 완료로 표기하지 않는다.

## 선행 조건

- ARKit 또는 ARCore 지원 스마트폰 1대 이상을 확보한다.
- iOS를 첫 대상으로 택할 경우 Mac, Xcode, Apple 서명 권한을 확보한다. Windows에서는 iOS Xcode 프로젝트 생성까지만 수행할 수 있다.

## 작업

- [ ] 1차 검증 기기 모델·OS를 기록하고, 반대 플랫폼 호환성 스파이크의 예정 기기 또는 확보 계획을 기록한다.
- [x] Unity LTS 버전과 호환되는 AR Foundation 및 선택 플랫폼 XR Plugin 버전을 확정한다.
- [x] Unity 프로젝트 루트 `<UNITY_PROJECT_ROOT>`와 버전 관리 저장소를 생성한다.
- [x] 프로젝트에 AR Foundation과 선택 플랫폼 XR Plugin을 설치한다.
