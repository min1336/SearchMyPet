# Task 04 — 캐릭터 프리팹 계약

## 목적

모델 자체의 축·피벗·크기 문제와 AR pose 계산 문제를 분리한다. 이후 페인팅을 붙여도 배치 규칙이 변하지 않게 최소 프리팹 계약을 고정한다.

## 선행 조건

- [ ] Task 02의 프리뷰 pose 규칙

## 작업

- [x] `<UNITY_PROJECT_ROOT>/Assets/Prefabs/ChameleonWallPlacementTarget.prefab`를 만든다.
- [x] prefab root의 앞 방향, 위 방향, 피벗 위치를 문서화한다. 컨트롤러가 요구하는 앞 방향과 모델 축을 일치시킨다.
- [x] 실제 높이의 시작값(권장 0.12~0.20m)과 벽 offset을 `<UNITY_PROJECT_ROOT>/Assets/Settings/WallPlacementConfig.asset`로 분리한다.
- [x] 흰 벽과 유색 벽에서 윤곽을 확인할 수 있는 임시 단색 재질을 적용한다.
- [ ] 정면·사선 관찰에서 벽 속 끼임, 뒤집힘, 과도한 부유가 없는지 확인한다.

## 수용 기준

- [ ] 서로 다른 방향의 벽에 배치해도 캐릭터가 90도 눕거나 벽의 뒤를 보지 않는다.
- [ ] 흰색·유색 벽에서 캐릭터의 윤곽과 벽으로부터의 작은 간격이 보인다.
- [x] 축, 피벗, scale, offset의 기준값이 코드 상수가 아닌 설정과 문서에 남아 있다.

## 제외

위장 페인팅, UV 읽기/수정, 텍스처 저장, 애니메이션 품질.
